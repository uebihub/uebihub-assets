# uebihub-assets

Arquivos públicos usados nas lojas atendidas pela UebiHub (ícones, imagens de catálogo).
Servidos pelo jsDelivr, fixados por commit: `https://cdn.jsdelivr.net/gh/uebihub/uebihub-assets@<commit>/<caminho>`

## santa-eulalia/icones
Ícones da Lucide (licença ISC, ver LICENSE-lucide.txt) recoloridos em marinho #25307E,
usados no CSS customizado do tema da Tray (`santa-eulalia/tray-css-icones.css`).
